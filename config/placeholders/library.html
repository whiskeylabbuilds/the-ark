The Reference Library isn't downloaded yet

The Reference Library (Wikipedia, medical guides, repair manuals and more) is a large download, about 100 GB, so the installer only plans it when you say yes.

To download it, open a terminal on the Ark and run:

cd ~/ark && scripts/download-zims.sh

It shows the sizes and your free space first. Downloads resume if they stop. This page turns into the library when it finishes.
